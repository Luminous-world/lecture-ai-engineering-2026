# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：
質問：
AIE2026の講座の宿題にある「3レベル」とは何ですか？
回答（要約）：
「3レベル」とは、受講生の現在のスキルや理解度、あるいは**課題の難易度（段階）に合わせて用意された3つのステップ（初級・中級・上級など）**を指している可能性が非常に高いです。
一般的には以下のような構成になっています。
1. **レベル1（基礎・初級 / Level 1）**
2. **レベル2（応用・中級 / Level 2）**
3. **レベル3（発展・上級 / Level 3）**

- 用語集の正しい意味と比べて気づいたこと：
用語集の正しい意味：
「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3段階
気づいたこと：
LLMは一般論な回答を行った。「可能性が非常に高い」と述べることでLLMが講座のことを知らないことを暗示した。今回の質問では、知らないことを事実であるかのように提示するハルシネーションは起こらなかった。

- 表示できたトークン数（入力 / 出力）：
質問：

英語では1単語＝1トークン程度、日本語では1〜2文字＝1トークン程度に変換されることが多いため、「LoRA とは何ですか？」という11文字のテキストが 8トークン となる

## 宿題

- 取り組んだレベル：
実装：`app/ask.py` を改修し、会話履歴を保ったまま続けて質問できるようにする 
- やったこと：
入力プロンプトを表示して入力を待ち受ける仕様に改良
会話履歴（コンテキスト）の自動維持は、google.genai SDK の client.chats.create(model=MODEL) セッションを利用
モデル選択機能を追加、最新の9モデルが選択可能
- 結果：
引数ありで起動した場合（例：uv run python -m app.ask "LoRAとは何ですか？"）、指定された最初の質問を実行・表示した後、そのまま対話ループに移行。
引数なしで起動した場合（例：uv run python -m app.ask）、即座に入力プロンプトを表示して対話モードを開始。
最新のgemini-4-argonを選択して質問すると
レート制限に達しました。1分ほど待ってから再実行してください。
gemini-3.8-flashを選択して質問すると、
モデルが混み合っています（503）。少し待ってから再実行してください。
gemini-3.7-flashを選択して質問すると、
10秒以上かかって回答が返ってきた。
- 気づき：
会話履歴を保つためにgenerate_content（単発呼び出し）から client.chats.create（チャットセッションの send_message）に変更すると、Gemini API に送信されるリクエストの内部データ構造が変わり、同じ質問（oRA とは何ですか？）でもトークン数の計算が 8 から 7 に変化した。
無料APIだとflashモデルでもWeb版のGeminiより回答時間が掛かる。
Google AI Studio の無料 API キーで Gemini を呼び出す場合、質問内容が Gemini の改善や学習に利用される可能性があるため、個人情報や機密情報を含む質問を行わないように注意する。
